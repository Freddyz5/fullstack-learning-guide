## 🧠 ¿Cómo funciona una web?
Una web funciona con cliente (navegador) y servidor.

## 📊 Esquema
```mermaid
flowchart LR
A[Usuario] --> B[Navegador]
B --> C[Servidor]
C --> D[Respuesta HTML/CSS/JS]
D --> B
```

## 🔑 Conceptos clave
- HTML → estructura
- CSS → estilos
- JS → lógica
