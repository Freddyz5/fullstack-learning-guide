## 🧠 ¿Qué es debugging?
Es encontrar y corregir errores en el código.

## 📊 Esquema
```mermaid
flowchart TD
A[Error] --> B[Revisar código]
B --> C[Encontrar problema]
C --> D[Corregir]
D --> E[Probar]
```

## 🔑 Conceptos clave
- Errores
- Logs
- Testing básico
