## 🧠 ¿Qué es Scrum?
Es un marco de trabajo ágil para colaborar y desarrollar software en equipos mediante iteraciones o ciclos cortos.

## 📊 Esquema
```mermaid
flowchart TD
A[Planificación del Sprint] --> B[Desarrollo / Daily]
B --> C[Review / Revisión]
C --> D[Retrospectiva / Mejora]
D --> A
```

## 🔑 Conceptos clave
- Sprint y Sprint Planning
- Product/Sprint Backlog
- Daily Standup Meeting
